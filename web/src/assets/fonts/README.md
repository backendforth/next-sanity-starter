# `src/assets/fonts`

Boilerplate keeps this folder empty. **Hosted font files** for `@font-face` live under **`public/fonts/`** (see `styles/typography/fonts.css` — `url("/fonts/…")`).

Prefer **WOFF2** and `font-display: swap`. Alternative: **`next/font/local`** or **`next/font/google`** in `layout.tsx`, then align `--font-family-*` with what Next emits.
